# Alam releases

Установщики десктопного приложения и фид автообновлений.

## Управление проектом
Задачи ведутся в Linear (MCP-сервер `linear` подключён через `.mcp.json`, авторизация: `/mcp` → linear).
**Перед любой работой прочитай `docs/linear-workflow.md`** и следуй ему: задача → ветка из Linear → PR с `Closes ALM-xxx`.
Ключевое: не начинать без задачи, не плодить дубли, ставить лейблы Type/Area/Priority, комментировать прогресс в задаче.
